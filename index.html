FAQ

Frequently asked questions

Everything you should know before booting up the trainer.

Is the trainer free and open source?+
Yes. Galactic Racer Trainer is completely free and the source code is publicly available. You can inspect exactly what it does, report issues, or contribute improvements through the GitHub repository linked on this page.
Will it work on Windows 10 and Windows 11?+
The trainer is built for 64-bit Windows 10 and Windows 11. It requires the game to be running in the same session, so launch the game first, then run the trainer as administrator for the process attachment to succeed.
Do the cheats persist after I restart the game?+
Unlocked pods and credits are stored in the game's save data, so they persist. Live toggles like speed hack, instant boost cooldown, and god mode are applied to memory and reset when you close the game — just re-enable them next session.
Is it safe to use, and can I get banned?+
The trainer is designed for single-player and offline use. It does not modify game files or phone home. As with any memory-editing tool, use it only in offline modes — using it in online or competitive sessions may violate the game's terms of service.
